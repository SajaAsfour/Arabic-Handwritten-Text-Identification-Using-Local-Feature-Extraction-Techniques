# ✍️ ENCS5343: Arabic Handwritten Text Identification Using Local Feature Extraction Techniques

## 📌 Overview
This repository contains my implementation of **Assignment #2: Arabic Handwritten Text Identification Using Local Feature Extraction Techniques** for the **ENCS5343: Computer Vision** course at **Birzeit University**. The assignment focuses on comparing **SIFT (Scale-Invariant Feature Transform)** and **SURF (Speeded-Up Robust Features)** for recognizing Arabic handwritten words.

## 🛠 Features
- ✅ **Dataset:** AHAWP (Arabic Handwritten Automatic Word Processing) dataset.
- ✅ **Feature Extraction Techniques:**
  - SIFT (Scale-Invariant Feature Transform)
- ✅ **Performance Metrics:**
  - Accuracy of feature matching
  - Execution time efficiency
  - Robustness to transformations (scale, rotation, illumination, noise)
  - Number of detected key points
- ✅ **Visualization & Analysis:** Graphs, matching results, and key point comparisons.

## 📂 Contents
- 📜 **Python Code:** Implementation of feature extraction, matching, and evaluation.
- 🗄 **Dataset:** AHAWP dataset for training and testing.
- 📊 **Results & Analysis:** Accuracy, execution time, robustness evaluations.
- 📄 **Report:** Methodology, experiments, results, and observations.
